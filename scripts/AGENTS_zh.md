# AGENTS.md — 门禁脚本

*[English](AGENTS.md)*

这个目录里的脚本管文档不变量，规则如下。

- **Node ESM，零依赖。** 门禁要在刚检出的仓库上直接跑，没有安装步骤。加了依赖，门禁恰好在要用它的时候用不了。
- **预算和例外在 `doc-budgets.json` 里。** 清单说了算；脚本只给它没列的文件兜底。别在任何文档里重复一个上限。
- **报位置，退非零。** 报 `path:line`，每条发现都打印，退 1。只会警告还放行的门禁，教所有人别理它。
- **空语料是失败。** 什么都没查的检查，什么都放行。
- **没见过的输入当敌意。** 清单格式坏了、链接跑出仓库，门禁就此停下，不降级成查一半。
- **证明检查拦得住。** 提交前，故意制造它该抓的缺陷，看它失败，再撤销。
