# 工作原理

*[English](how-it-works.md)*

![本机、私有仓、另一台电脑](flow.png)

会话在磁盘上就是一个文件，同步因此不需要服务器：仓库是传输通道，一次提交就是一次传输的单位。

## 仓库

```
README.md                        生成的索引：项目、会话、设备
manifest.json                    权威索引：id → 路径、原 cwd、sha、附件
<project>/sessions/<id>.jsonl.zstd   会话本体，DSH 自己的格式
<project>/attachments/<sha>.<ext>    会话引用的附件
<project>/files/<relative path>      工作区文件，开了文件同步才有
```

`manifest.json` 记着每条会话的**原 `cwd`**。接力能成靠的就是它：下载时它变成目标机器的工作区路径，会话头跟着改写。

## 会话文件

一条会话是 JSONL 流，压成**多个 zstd 帧**：第一帧放头部（`cwd` 等字段），之后每批记录各成一帧追加上去。这个文件生来只增不改。

DSH 校验会话，比的是文件的实际路径和 `header.cwd` 推出的路径。两者对不上，就算文件损坏。

## 设计取舍

**只重编码头部这一帧。** 改写 `cwd` 只碰第一帧，其余一概不动。后面的帧若重新编码，追加式的字节链就断了，前缀比对从此失灵。

**路径即身份，`cwd` 和目录名必须一起变。** 目录名是 `cwd` 编码的结果；只改一边，DSH 就不认这条会话，拒绝加载。

**冲突检测比正文，不比头部。** 各台机器的头部 `cwd` 本来就不一样，同步状态和分歧只看头部之后的字节。一方是另一方的字节前缀，短的那方追上去就是；谁也不是谁的前缀，这条会话就是分歧了。

**分歧的会话绝不悄悄调和。** 下载时保留本地文件，远端那份存在旁边，改名 `*.remote-fork-<stamp>`；下载也提供强制选项，明明白白选定一边。DSH 在一轮结束时改写日志尾部（被打断的工具结果换成真正的结果），所以两端分歧多半是两边都真在干活，不是 bug。

**注册必须走服务接口。** 下载的会话用 `workspaceRegistry.attachSession()` 挂载，绝不直接改 `workspace.json`：那个文件归宿主，它会拿内存覆盖外部改动。宿主还缓存会话头，DSH 运行期间 `cwd` 变了的会话一律拒收，直到 DSH 重启。

**空仓库要先有种子提交。** 零提交的仓库对 `POST /git/blobs` 一律回 409，所以第一颗种子走 Contents API 建。

**附件只补传，不重传。** 会话正文没变、上传判成 `skip` 时，它引用而远端索引没列的附件，仍会单独推上去。

**附件还原有兜底。** 下载时既读 `manifest.json` 的清单，也从会话正文里解析 `sha256:` 引用；索引过期时，去远端目录树里找 `<project>/attachments/<sha>.*`。

**前缀比对不花网络。** `manifest.json` 记着每次上传的正文长度和哈希，预览只要切一刀本地文件，就能判定“这是早先那版又多几帧”。2MB 的会话几秒出预览，不用等几分钟。

## 安全边界

插件只写四个位置，别无其他：

| 路径 | 用途 |
|---|---|
| `$DSH_HOME/github-sync/` | 自己的状态、历史、诊断 |
| `$DSH_HOME/sessions/` | 你下载或删除的会话 |
| `$DSH_HOME/attachments/v1/objects/` | 你还原或回收的附件 |
| 当前工作区（**默认关闭**） | 文件和文件夹同步 |

它不启动进程、不执行命令、不写注册表项、不改 hosts、不动环境变量、不装代理，只联系 `api.github.com` 和 `github.com`。

其余限制：

- **只用私有仓。** 公开仓在测试连接和提交两处都过不去。
- **形似密钥的文件一律拦掉**：`.env*`、`*.key`、`*.pem`、`*.pfx`、`*.p12`、`*.kdbx`、`*.keystore`、`id_rsa`、`id_ed25519`、`id_ecdsa`、`.npmrc`、`.netrc`。
- **远端来的路径，先验证再用。** 会话 id、附件 sha、相对路径都要对照预期格式和拼接的根目录查一遍，索引中了毒也写不出 `$DSH_HOME`。
- **令牌只存在宿主进程里。** 它放在 DSH 的凭据存储中，不回传浏览器。

[`tools/audit-safety.mjs`](../tools/audit-safety.mjs) 静态检查这些不变量。

## 跨平台

插件是纯 JavaScript：没有原生模块，没有平台分支，Windows 和 macOS 跑同一份代码。

唯一因平台而异的，是工作区路径怎么变成会话目录名。`lib/projectkey.mjs` 按 DSH 的算法编码（盘符和分隔符一律折成 `-`）；算出的目录不存在时，`lib/sessiondir.mjs` 退一步，从会话头里读绝对 `cwd`。某个平台的目录名算法就算有别，也藏不住一台机器的会话。

接力把头部 `cwd` 改写成目标工作区，所以 Windows 上写的会话能在 macOS 打开，反过来也行。
